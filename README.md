# Data Imputation Model for Athletic Performance

## Overview
This project predicts missing values in an athletic performance dataset covering three seasons. It combines K-Means Clustering, XGBoost Regressor, and Softmax Similarity to estimate missing values.

## Approach
- Cleaned and standardized raw data to resolve formatting inconsistencies.
- Used K-Means Clustering to group similar records.
- Combined XGBoost regression and Softmax Similarity to estimate missing values.
- Compared the model with MICE (Multivariate Imputation by Chained Equations).

## Results
The model achieved accuracy comparable to MICE while improving computational efficiency on the sports dataset used for evaluation.
